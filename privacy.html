Политика конфиденциальности приложения toon-replies

Обновлено: 23 ноября 2026

toon-replies — служебное приложение YouTube-канала «А что, если?» (@achtoesli_toons). Им пользуется только владелец канала, для своего собственного канала. Других пользователей у приложения нет.

Какие данные используются

  • YouTube Data API (разрешение youtube.force-ssl): чтение комментариев под роликами канала и публикация ответов от имени канала.
  • YouTube Analytics API (разрешение yt-analytics.readonly): чтение статистики роликов канала — просмотры, удержание, время просмотра, подписки.

Как используются данные

  • Текст новых комментариев передаётся сервису ИИ, чтобы подготовить короткий ответ в стиле канала. Ответ публикуется под тем же комментарием.
  • Статистика нужна владельцу, чтобы понимать, какие ролики нравятся зрителям.
  • Данные не продаются, не передаются для рекламы и не используются ни для чего, кроме работы этого канала.

Хранение

Ключ доступа и журнал ответов хранятся на компьютере и сервере владельца канала. Журнал содержит текст комментария и нашего ответа и нужен, чтобы не отвечать дважды. Удалить данные можно в любой момент; отозвать доступ приложения — на странице Сторонние приложения с доступом к аккаунту.

Использование данных, полученных через API Google, соответствует Правилам использования данных пользователей сервисов API Google, включая требования об ограниченном использовании (Limited Use). Приложение также подчиняется Условиям использования YouTube и Политике конфиденциальности Google.

Privacy Policy — toon-replies

Last updated: November 23, 2026

toon-replies is an internal tool of the YouTube channel “А что, если?” (@achtoesli_toons). It is used only by the channel owner, for the owner's own channel. It has no other users.

Data accessed

  • YouTube Data API (scope youtube.force-ssl): reading comments on the channel's videos and posting replies as the channel.
  • YouTube Analytics API (scope yt-analytics.readonly): reading the channel's video statistics (views, retention, watch time, subscribers).

How data is used

  • The text of new comments is sent to an AI service to draft a short reply in the channel's voice; the reply is posted under the same comment.
  • Statistics help the owner understand which videos viewers like.
  • Data is not sold, not shared for advertising, and not used for anything other than running this channel.

Storage

The access token and a reply log are stored on the channel owner's computer and server. The log holds the comment text and our reply, so the same comment is not answered twice. Data can be deleted at any time; access can be revoked at Google Account → Third-party access.

toon-replies' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also follows the YouTube Terms of Service and the Google Privacy Policy.
